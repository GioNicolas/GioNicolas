### 🚀 What I'm working on

- **[Catenary](https://thecatenary.app)** — the IDE for coding agents. Your editor, terminals and agents in one window, talking to each other: wires pass work from one agent to the next, and Maestro Mode lets one agent assemble its own team. macOS · Windows · Linux, installable with `winget install catenary` or [Homebrew](https://github.com/GioNicolas/homebrew-catenary). [Releases →](https://github.com/GioNicolas/catenary-releases)
- **remedIA** — a medication assistant that lives entirely inside WhatsApp, built with the team at [TRIL Lab](https://tril.ci.ufpb.br/) (UFPB): register a medicine by text, voice or a photo of the box, get reminded on time, and read the leaflet warnings that matter.
- **[Where to Review First](https://github.com/GioNicolas/pesquisa-onde-revisar)** — research: can an AI agent's execution trace tell a reviewer which hunks of its patch to look at first? *Exploratory.*
- **[S.E.E.D.](https://github.com/GioNicolas/S.E.E.D)** — a research proposal for a model that learns explicit rules and relations, and revises them when it fails. *Conceptual.*
